About

Chopper Noise combines recorded helicopter flights, certified noise levels and Census counts to show who hears helicopters over New York City and the Hudson waterfront.

Why

Helicopters fly low over New York City and the Hudson waterfront. Tours and charters share that air with police, medical and military flights. This site counts the residents who hear each flight, and how many flights each block hears in a day. It keeps non-essential and public-service flights apart.

Scope

The map replays three recorded days in August and September 2026. Loudness is modeled from each flight's position and helicopter type. Residents are counted by 2020 Census block, in New York City and the New Jersey blocks nearby. The site shows no registration or owner for any aircraft. The Data page has the sources, the method and the limits.

Built

A static website using MapLibre GL JS, with OpenFreeMap tiles. A Python pipeline, using only the standard library, reads the flight archives, models each flight's peak level at every Census block and writes the files the map reads. The browser repeats the pipeline's level formula as it replays a day. The site uses no account system or analytics.

Independence

No agency reviewed this site.

Reuse

Code is BSD 3-Clause licensed. Compiled data can be reused with attribution; the source data retain their own terms. Carry the day and the level, such as 60+ dBA, and say the figure is modeled when republishing it. The download is on the Data page.

Contact

The source is on GitHub. Report an issue there. For a data issue, include the day, the time and the place on the map.
